Guia de componentes

Abrir suíte interativa

Referência para reaproveitar os elementos no projeto original. Todos os estilos estão em automacao-ui.css; os componentes usam apenas classes au-*, atributos ARIA e atributos data-* de estado. Nenhum JavaScript é exigido para a aparência: o código da aplicação só altera atributos.

1. Instalação e tema

<link rel="stylesheet" href="automacao-ui.css">

<!-- data-au-theme: light | dark | auto (segue o sistema) -->
<!-- data-au-accent: ciano | verde | ambar | violeta | azul -->
<div class="au-root" data-au-theme="auto" data-au-accent="ciano"> … </div>

// Trocar tema em tempo de execução
document.querySelector('.au-root').dataset.auTheme = 'dark';

Os tokens são recalculados no elemento que recebe data-au-theme. Para criar um acento novo, declare um bloco [data-au-accent="nome"] com as 10 variáveis --au-accent-* e --au-on-accent.

Regras de uso

  • Habilite um controle somente quando a função e os valores aceitos pelo equipamento estiverem confirmados (Capacidades → leitura validada → escrita liberada).
  • Envie valores contínuos ao soltar (pointerup) ou após 600 ms sem teclas; nunca a cada movimento.
  • Enquanto houver operação pendente, use data-status="pending" e disabled para impedir cliques repetidos.
  • Ações sensíveis e comandos em grupo passam pelo modal de confirmação com equipamento e função explícitos.
  • Com o serviço local desconectado, aplique disabled em todos os comandos e exiba os estados como último valor conhecido.
  • Estado nunca é indicado só por cor: cada indicador combina forma do ponto e texto.
